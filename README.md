# 🐻 Wildlife Dashboard - 獣害対策データ分析ダッシュボード

## 概要

猟友会や自治体職員が屋外（山林）で使用することを想定した、React Native / Expo 製の野生動物検知ダッシュボード。

**直射日光下でも読みやすく、軍手で操作できる実用的な設計。**

---

## ✨ 主な特徴

### 1️⃣ **視認性優先設計**
- 🌞 直射日光下でも読める高コントラスト（黒背景 × 白テキスト）
- 📏 大きなフォントサイズ（最小13px、タイトル22px以上）
- 🎨 動物の危険度を色で一目瞭然
  - 🔴 **クマ** = 赤（緊急）
  - 🟠 **イノシシ** = オレンジ（要注意）
  - 🟢 **シカ** = 緑（安全）

### 2️⃣ **操作性優先設計**
- ✋ 軍手装着でも操作可能
- 🎯 最小タップ領域 **60×60px**
- 📍 十分な要素間余白（マージン 16px 以上）
- 📱 片手での操作を想定したレイアウト

### 3️⃣ **実務的な機能**
- 📊 **サマリータイル**: 過去24時間の総検知数 & 主要動物
- 📈 **出没傾向グラフ**: 時間帯別検知頻度（棒グラフ、危険度別色分け）
- 🗺️ **罠設置推奨エリア**: スコア（出没頻度 × 慣れ度合い）でランク表示
- 🔄 **リアルタイム更新**: ワンタップでデータを更新

## 🚀 クイックスタート

### 前提条件
- Node.js 16 以上
- npm または yarn
- Expo CLI

### セットアップ（5分）

```bash
# 1. Expo プロジェクトを初期化
npx create-expo-app WildlifeDashboard
cd WildlifeDashboard

# 2. WildlifeDashboard.js を App.js に配置
cp WildlifeDashboard.js App.js

# 3. 依存関係をインストール
npm install
# または
yarn install

# 4. アプリを起動
npm start

# iOS で実行（Mac 必須）
npx expo run:ios

# Android で実行
npx expo run:android

# Web ブラウザで確認
npx expo run:web
```

```javascript
      {
        species: 'イノシシ',
        count: 28,
        riskLevel: 'high',        // 'critical' | 'high' | 'low'
        color: '#FF9800'
      },
      // ...
    ]
  },
  timeSeriesData: [
    { hour: '0:00', detections: 2, label: '0' },
    // ... 24時間分のデータ
  ],
  trapAreas: [
    {
      areaId: 1,
      areaName: '北尾根エリア',
      score: 8.7,               // 罠設置推奨スコア
      detections: 24,
      frequency: 'very_high'    // 出没頻度
    },
    // ...
  ]
}
```

## 🔧 カスタマイズ例

### 1. 新しい動物を追加

```javascript
// DUMMY_DATA.summary.topAnimals に追加
{
  species: 'タヌキ',
  count: 5,
  riskLevel: 'low',
  color: '#9C27B0'  // 紫色
}
```

### 2. グラフの色を変更

```javascript
// TrendChart コンポーネント内の bar backgroundColor
backgroundColor:
  item.detections > 7
    ? '#E91E63'  // 赤ピンク
    : item.detections > 4
    ? '#9C27B0'  // 紫
    : '#673AB7',  // 深紫
```

### 3. フォントサイズを大きく（高齢者対応など）

```javascript
// styles.headerTitle
fontSize: 32,  // 28 から拡大
```

## 🐛 トラブルシューティング

| 問題 | 解決策 |
|------|--------|
| アプリが起動しない | `npx expo start --clear` でキャッシュ削除 |
| データが表示されない | コンソールでエラーを確認、DUMMY_DATA の形式確認 |
| 画面がぼやける | 背景色 (#1a1a1a) とテキスト色 (#FFFFFF) を確認 |
| タップが反応しない | minHeight: 60 が設定されているか確認 |
| スクロールが重い | FlatList への置き換えを検討 |
